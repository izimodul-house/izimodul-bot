# izimodul-bot

Telegram-бот для склейки коротких видеороликов в один ролик (мультик) с плавными переходами (crossfade) между клипами.

## Как это работает

1. Пользователь отправляет боту команду `/new`, чтобы начать новую подборку.
2. Присылает видео по одному, в том порядке, в котором они должны идти в итоговом ролике.
3. Открывает `/menu` и настраивает ролик кнопками: длительность, текст, музыку (см. ниже).
4. Нажимает «🎬 Собрать ролик» в меню (или отправляет `/render`) — бот склеивает все клипы с плавным crossfade-переходом, применяет настройки и присылает готовый файл.

Длительность перехода между клипами можно задать явно: `/render 0.8` (в секундах, по умолчанию 0.5).

## Настройки ролика (меню на кнопках)

`/menu` открывает интерактивное меню — все параметры выбираются кнопками, без ввода команд:

- **⏱ Длительность** — пресеты 10/15/30/60 сек, «Своё значение» (бот попросит прислать число) или «Без ограничения»
- **📝 Текст** — выбор позиции (верх/центр/низ), «Ввести текст» (бот попросит прислать текст) и «Убрать текст»
- **🎵 Музыка** — инструкция прислать аудио/голосовое сообщение (можно в ответ на подсказку бота или командой `/music`, ответив на аудиофайл) и «Убрать музыку»
- **🎬 Собрать ролик** — появляется, когда добавлено 2+ клипа
- **🆕 Новая подборка клипов** — очищает клипы, настройки (длительность/текст/музыка) сохраняются

Настройки привязаны к чату и переживают `/new` — удобно, если делаешь несколько роликов подряд в одном стиле.

Текст накладывается через фильтр `subtitles` (libass) с собственным шрифтом из `assets/fonts` — так наложение текста не зависит от шрифтов, установленных в системе.

## Установка

```bash
npm install
cp .env.example .env
# впиши токен бота, полученный от @BotFather, в .env
npm start
```

ffmpeg и ffprobe устанавливать отдельно не нужно — используются бинарники из пакетов `ffmpeg-static` и `ffprobe-static`.

## Команды

- `/start` — краткая инструкция и меню
- `/menu` (или `/settings`) — открыть меню настроек на кнопках
- `/new` — начать новую подборку клипов (очищает предыдущую)
- `/render [секунды]` — склеить накопленные клипы с crossfade и прислать результат (то же самое, что кнопка «Собрать ролик»)
- `/music` (в ответ на аудио/голосовое сообщение) — задать фоновую музыку; `/music off` — убрать
- `/list` — сколько клипов уже добавлено
- `/cancel` — очистить текущую подборку без склейки

## Ограничения

- Максимум 30 клипов в одной подборке (см. `MAX_CLIPS` в `src/index.js`).
- Итоговое видео отправляется через обычный Bot API, поэтому действует лимит Telegram на загрузку файлов ботом (около 50 МБ).
- Если у части клипов нет звуковой дорожки, итоговый ролик собирается без звука (чтобы избежать рассинхрона).
