# CLAUDE.md — правила для агента в этом репозитории

## Проект
`izimodul-bot` — Telegram-бот на grammy для склейки коротких видео в один ролик
с crossfade-переходами (ffmpeg-static/ffprobe-static). Точка входа: `src/index.js`.

## Стиль общения
- Краткость и результат первым, без лишних объяснений
- Отвечай на русском
- Прямой фидбек от владельца («не надо», «не так») — принимай и корректируйся сразу

## Workflow
- Нетривиальная задача (3+ шагов) — сначала короткий план, потом код
- Что-то пошло не так — остановись и перепланируй, не продавливай
- Перед «готово» — проверь: запускается ли бот, нет ли синтаксических ошибок,
  соответствует ли поведение README

## Принципы
- Минимальные изменения под задачу, без побочного рефакторинга
- Не добавлять абстракции и настройки, которых не просили
- Искать корневую причину бага, а не обходить симптом

## Git
- Коммиты содержательные, на русском
- Не пушить в main напрямую без явного запроса пользователя
- Не использовать `--no-verify`, force push, перезапись истории без разрешения

## Зелёная зона (делаю сам)
Правки кода и README в рамках задачи, локальный запуск/проверка, мелкие фиксы

## Красная зона (спрашиваю владельца)
git push, изменение зависимостей в package.json, изменение лимитов
(MAX_CLIPS, лимиты Telegram), архитектурные изменения, удаление файлов

## Безопасность
- Никогда не вывожу и не коммичу токены/секреты (.env, BOT_TOKEN)
- Не коммитить .env — он уже в .gitignore, проверять перед коммитом
- Бэкап/осторожность перед изменением файлов, которые нельзя откатить одной командой

## Запреты
- Не выдумывать данные и цифры — если не знаю, так и говорю
- Не удалять код без причины и не менять то, о чём не просили
